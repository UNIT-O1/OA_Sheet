## The Problem

> [!WARNING]
> You don't fail Online Assessments because you didn't practice. **You fail because you didn't revise.**

Spreadsheets forget. Random problem lists have no order. Solving something once feels like learning it, until the timer starts.

This tracker fixes that. Pick a pattern, solve six problems, code them cold, and revisit them on a schedule until they stick.

## How To Use It

> [!TIP]
> Pattern recognition is built by spacing, not cramming.

| Step | Action |
| :---: | :--- |
| ![01](https://img.shields.io/badge/01-2563eb?style=flat-square) | Take **3 patterns at a time**. Finish them before opening the next tier. |
| ![02](https://img.shields.io/badge/02-7c3aed?style=flat-square) | Follow the **2-2-2 rule.** Problems 1-2 teach the template. 3-4 build speed. 5-6 test edge cases. |
| ![03](https://img.shields.io/badge/03-059669?style=flat-square) | Finished a pattern? **Write its template from memory** on paper before moving on. |
| ![04](https://img.shields.io/badge/04-ea580c?style=flat-square) | **Re-solve after 3-4 days.** Tick Revision 1, 2 and 3 as you go. |

## Get Started

```text
.
├── dsa_tracker.html          # the dashboard
├── dsa_roadmap_tracker.pdf   # the printable sheet
└── README.md
```

1. Clone or download this repo.
2. Open `dsa_tracker.html` in Chrome, Edge, Firefox, Safari or Brave.
3. Click a problem, solve it, tick the boxes.

> [!IMPORTANT]
> Start with Pattern 01 today.
